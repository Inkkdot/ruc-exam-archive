# RUC Past Exam Archive · 人大历年考题收集

Past exam papers, quiz sheets, answer keys and exam reviews from **Renmin University of China (RUC)** open courses.
Collected in bulk from the public courseware area of RUC's OBE open-course platform, then de-duplicated and grouped by course.

## 这是什么

中国人民大学开放课程平台（OBE，现 UniCourse）**公开课件区的全量收集**成果：把所有公开课程里带「期中 / 期末 / 小测 / 考试」字样的材料全部拉下来，
再剔除单纯的复习串讲和成绩单、考场安排等行政文件，剩下的就是这份按课程归并的历年考题集合。

- 采集时间：2026-11-05
- 规模：**17 门课程 · 36 个教学班 · 61 个文件**
- 结构：小测 36 · 期中 15 · 期末 4 · 其他讲评 6

## 收录口径

| 保留 | 剔除 |
|---|---|
| 小测 / 随堂测 / 章节测验的题目与答案 | 纯复习提纲、知识点串讲（「期末复习-汇总」这类） |
| 期中、期末试卷（含 Midterm 卷） | 成绩单、成绩分布 |
| 试卷讲评、参考答案、易错题 | 座位表、考试安排、考场纪律、答题纸上传流程 |
| 考试范围与题型说明 | 大作业要求与报告模板 |

## 目录结构

```
files/<课程名>/<教学班名__课程编号>/<文件>
```

同一门课的不同教师、不同年份都放在同一个课程文件夹下。例如 `数据库系统概论/` 下有 2014–2024 共 8 个教学班。
